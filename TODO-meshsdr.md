## Confirmed RX Defect: CFO/STO/Dechirp-Pfad
* **Status:** ⚠️ CONFIRMED DEFECT (2026-08-23)
* **Description:** The RX CFO/STO/Dechirp path is defective and fails to maintain timing/phase on independent signals. It has been empirically tested against a `meshtastic_test.cf32` ground-truth file generated by `gen_meshtastic_iq.py` (gr-lora_sdr). While the preamble is correctly detected, the extracted raw symbols (e.g. 937, 49, 29, 1021...) do not match the expected gray-mapped symbols (1297, 369, 1985...) and the drift is non-constant (e.g. 360, 320, 1956, 1216...).
* **Next Steps:** The CFO/STO/Dechirp-Pfad must be systematically debugged against the now-available ground-truth data in `tests/fixtures`.
